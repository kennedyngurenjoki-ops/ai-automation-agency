# Setup and launch checklist

Use [README.md](README.md) for the Vite/Node commands. The old Create React App instructions no longer apply.

Before launch, approve the business identity/contact, privacy/retention policy, offer/prices, hosting costs, HTTPS/proxy rules and persistent disk. Verify backup/restore, restart persistence, operator review, failure handling and deletion requests on the real host. Resolve browser CI and review all tests before merging.

See [deployment](docs/DEPLOYMENT.md), [security](docs/SECURITY.md), [verification](docs/VERIFICATION.md) and the [commercial plan](docs/COMMERCIAL_PLAN.md). No deployment, purchase, outreach or customer payment is performed by preparing this review branch.
